## Recreate the existing RF1 services

Only use this with the existing RF1 schema 0013 database and original budget network.
From `code/`, after the user has renewed their existing AWS CLI login when necessary:

```powershell
$env:BRAIN_WEB_PORT = '5189'
$env:BRAIN_BACKEND_IMAGE = 'linkmind-rf1-backend:ai-v7'
$env:AWS_CONFIG_HOME = Join-Path $env:USERPROFILE '.aws'
$env:AWS_PROFILE = 'default'
$env:AWS_REGION = 'us-east-1'
$env:BRAIN_RF1_DB_HOST = 'linkmind-rf1-validation-db-1'
$env:BRAIN_BUDGET_NETWORK = 'linkmind-company-sonnet_default'
$env:BEDROCK_BUDGET_DATABASE_URL = 'postgresql+psycopg://brain:brain-local@linkmind-company-sonnet-db-1:5432/brain'
docker compose -p linkmind-rf1-validation -f compose.yaml -f compose.bedrock.yaml -f compose.rf1-ai.yaml up -d --no-deps --no-build --wait api worker
```

Inspect `/api/v1/runtime` with the local authorized demo identity before testing. The
response must report Bedrock and the original cumulative budget. Do not apply these
commands to main or older-schema previews. `scripts/rf1_ai_smoke.py` is a bounded,
answer-only acceptance utility, not an instruction to repeat the paid questions.
